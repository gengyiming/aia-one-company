# 客户 Pipeline

## Pipeline 总览

```dataview
TABLE status AS "状态", category AS "需求类别", next_followup AS "下次跟进", source AS "来源"
FROM "02-business-dev/cases"
WHERE status != "已成交" AND status != "已流失"
SORT next_followup ASC
```

## 阶段说明

| 阶段 | 说明 | 关键动作 |
|------|------|---------|
| 新线索 | 刚获得联系方式 | 初次接触，建立关系 |
| 已接触 | 已初步沟通 | 约定FNA时间 |
| 需求分析中 | 正在做FNA | 完成需求分析，设计方案 |
| 方案呈现 | 已提交方案 | 解答疑问，处理异议 |
| 促成中 | 客户有意向 | 促成签单 |
| 已成交 | 已签单 | 售后服务，转介绍 |
| 已流失 | 暂时不跟进 | 定期保持联系 |
