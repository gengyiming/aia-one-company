# 销售手册 — 业务拓展SOP

## 销售流程总览

```
1. 线索获取 → 2. 初次接触 → 3. 需求分析 (FNA) → 4. 方案设计
     → 5. 方案呈现 → 6. 异议处理 → 7. 促成签单 → 8. 售后转介
```

## 1. 线索获取渠道

| 渠道 | 说明 | 优先级 |
|------|------|--------|
| 转介绍 | 现有客户推荐，成交率最高 | ⭐⭐⭐ |
| 个人品牌内容 | 朋友圈/小红书/LinkedIn引流 | ⭐⭐⭐ |
| 自然市场 | 亲友、同学、前同事 | ⭐⭐ |
| 活动获客 | 讲座、工作坊、社交活动 | ⭐⭐ |
| 内地客户 (MCV) | 高才通、GBA跨境客户 | ⭐⭐ |

## 2. 初次接触要点

- 建立信任优先，不急于推产品
- 了解对方基本情况和关心的话题
- 约定下一次正式见面时间
- 详见 [[scripts/需求分析框架|需求分析话术]]

## 3. 需求分析 (Financial Needs Analysis)

标准FNA流程：
1. 家庭结构与责任
2. 现有保障盘点
3. 保障缺口分析
4. 优先级排序
5. 预算确认

详见 [[scripts/需求分析框架]]

## 4. 方案设计原则

- 先保障后储蓄（保障是地基）
- 量力而行（保费占收入10-15%为宜）
- 分阶段规划（不必一步到位）
- 详见 [[templates/方案建议书框架]]

## 7. 售后与转介绍

- 成交后1周内感谢回访
- 协助客户完成所有手续
- 3个月后首次保单检视
- 自然引导转介绍
- 转交 [[03-customer-service/服务手册|客户服务部]] 进行长期维护
