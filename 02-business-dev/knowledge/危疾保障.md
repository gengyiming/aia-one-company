# 危疾保障知識庫

## 为什么需要危疾保障

危疾保障 ≠ 医疗保障。两者的区别：

| | 医疗险 | 危疾险 |
|--|--------|--------|
| 赔偿方式 | 实报实销（按实际医疗费用） | 一笔过赔偿（确诊即赔） |
| 用途限制 | 只能用于医疗费用 | 自由支配 |
| 核心价值 | 覆盖医药费 | 覆盖收入损失、康复费用、生活开支 |

## 产品类型

### 多重赔付危疾（主推）
- 癌症可多次赔偿（每次间隔期通常3年）
- 不同疾病组别分别赔偿
- 总赔偿可达保额的多倍
- **AIA代表产品**：加裕智倍保系列

### 单次赔付危疾
- 一次严重疾病赔偿后合约结束
- 保费较低，适合预算有限客户
- 通常作为入门保障

## 保额建议

```
建议保额 = 年收入 × 3-5年
（假设患重病后需要2-3年康复期，期间无法正常工作）

示例：
年收入 $60万
建议保额 = $60万 × 3-5 = $180万-$300万
```

## 核心卖点

1. **确诊即赔**：不需要住院，确诊就赔偿
2. **现金自由支配**：可以用于最好的治疗、出国就医、请护工、生活费
3. **多重保障**：不幸再次患病，还能获得赔偿
4. **早期保障**：轻症也有赔偿（通常为保额20-25%）
5. **越早买越便宜**：年龄是保费最大的影响因素

## 常见疾病覆盖

- 癌症（最常见的索赔原因）
- 心脏病（心脏病发作、冠状动脉手术）
- 中风
- 器官移植
- 肾衰竭
- 以及数十种其他严重疾病

## 内地客户特别关注点

- 香港危疾险保费通常比内地便宜20-30%
- 全球保障，在内地确诊也可索赔
- 美元/港币保单，资产配置多元化
- 理赔流程简单，可远程处理

## 常见搭配

- 危疾 + 医疗 = 疾病全面保障（一个赔现金，一个赔医疗费）
- 危疾 + 人寿 = 基础保障组合
