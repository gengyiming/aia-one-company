# 醫療保障知識庫

## VHIS 自愿医保计划

### 什么是 VHIS
- 政府认可的医疗保险标准框架
- 保证续保至100岁，不因健康变化拒保
- 保费可扣税（每名受保人每年最高 $8,000）
- 涵盖未知的已有疾病（设等候期）

### VHIS 标准计划 vs 灵活计划
| | 标准计划 | 灵活计划 |
|--|---------|---------|
| 保障范围 | 基本住院保障 | 大幅增强，可包含门诊 |
| 每年保障限额 | $42万 | 可达数百万至无上限 |
| 保费 | 较低 | 较高但保障全面 |
| 适合 | 预算有限 | 追求全面保障 |

### 扣税计算
```
个人：最高扣 $8,000/年
一家四口：$8,000 × 4 = $32,000/年扣税额
实际税务减免 = 扣税额 × 税率（最高17%）
即最多节省 $32,000 × 17% = $5,440/年
```

## 高端医疗险

### 核心卖点
- 全球保障（含美国或不含美国）
- 无终身限额（或极高限额）
- 私家病房/半私家病房
- 涵盖癌症治疗、器官移植等高额医疗费用

### 适合客户画像
- 希望享受私家医院服务
- 家庭经济支柱需要最好的医疗保障
- 经常出差/旅行的高管
- 内地客户寻求境外医疗保障

## 医疗险 vs 危疾险（常见混淆）

| 场景 | 医疗险 | 危疾险 |
|------|--------|--------|
| 住院手术 | ✅ 赔医疗费 | ❌（除非确诊危疾） |
| 确诊癌症 | ✅ 赔治疗费 | ✅ 一笔过赔偿金 |
| 康复期不能工作 | ❌ | ✅ 赔偿金可覆盖收入损失 |
| 赔偿限制 | 按实际费用 | 按保额 |

**给客户的解释**：
> 「医疗险管你看病的钱，危疾险管你不能工作时家庭的钱。两个不一样，最好都有。」

## 公司团体医疗险的局限

提醒客户团险的常见限制：
1. 离职即失效
2. 保额通常有上限
3. 不包含严重疾病的长期治疗
4. 家属覆盖可能有限
5. 不能累积无索赔优惠
