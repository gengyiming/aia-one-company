# 人寿保障知识库

## 产品类别

### 定期寿险 (Term Life)
- **特点**：纯保障，无储蓄成分，保费最低
- **适合**：年轻家庭、高负债人群，用最低成本获得最高保障
- **保障期**：10/20/30年，或保到指定年龄
- **建议保额**：年收入 × 5-10倍 + 房贷余额 + 子女教育基金

### 终身寿险 (Whole Life)
- **特点**：终身保障 + 现金价值累积
- **适合**：有财富传承需求的客户
- **附加价值**：保单贷款功能、身故赔偿确定性

### 万用寿险 (Universal Life)
- **特点**：灵活保费和保额调整，现金价值有最低保证利率
- **适合**：高净值客户，用于资产传承和税务规划
- **特色**：可大额趸交，杠杆效果明显

## 保额计算方法

```
建议保额 = (家庭年支出 × 替代年数) + 未偿还贷款 + 子女教育基金 - 可变现资产 - 配偶收入折现

示例：
家庭年支出 $40万 × 10年 = $400万
房贷余额 = $300万
子女教育基金 = $200万
合计需要 = $900万
减：配偶可覆盖部分 = $300万
净保额需求 = $600万
```
