# 需求分析框架 (FNA)

## 开场话术

> 「今天我想用大概30-45分钟的时间，全面了解你和家人目前的保障状况。这不是要推销任何产品，而是像做身体检查一样，帮你看看财务保障方面有没有需要注意的地方。好吗？」

## 第一步：了解家庭状况

### 必问问题

1. **家庭结构**
   - 婚姻状况？配偶职业和收入？
   - 子女几个？年龄？教育规划？
   - 父母是否需要赡养？

2. **收入与支出**
   - 家庭年收入大约是多少？（范围即可）
   - 主要固定支出？（房贷/房租、生活费、教育费）
   - 目前每月可用于保障规划的预算？

3. **资产与负债**
   - 是否有房产？房贷余额？
   - 其他贷款或负债？
   - 应急储备金大约多少？

## 第二步：现有保障盘点

### 必问问题

1. 目前有没有买过保险？（人壽/危疾/醫療/意外/儲蓄）
2. 是哪家公司的？大约保额是多少？
3. 公司有没有提供团体医疗保险？覆盖范围如何？
4. 有没有做过 MPF 以外的退休规划？

> **提示**：如果客户有现有保单，建议做一次完整的保单检视。可链接 [[03-customer-service/scripts/年度保单检视话术]]

## 第三步：保障缺口分析

### 五大保障支柱

| 支柱 | 需要评估的内容 | 参考 |
|------|--------------|------|
| 🛡️ 人壽保障 | 如果不幸身故，家人需要多少钱维持生活？（收入替代 x 年数 + 负债 + 教育基金） | [[knowledge/人寿保障]] |
| 🏥 危疾保障 | 万一患重病，需要多少钱覆盖治疗+康复期收入损失？（建议年收入3-5倍） | [[knowledge/危疾保障]] |
| 🏨 醫療保障 | 住院/手术费用是否有足够覆盖？VHIS扣税额度？ | [[knowledge/医疗保障]] |
| 💰 儲蓄保險 / 投資成分保險 | 中长期财务目标：子女教育、退休、置业 | [[knowledge/储蓄投资]] |
| 👴 退休收入 | 预期退休年龄？退休后每月需要多少？MPF之外是否有补充？ | [[knowledge/退休规划]] |

### 缺口计算框架

```
人壽保障缺口 = (家庭年支出 × 替代年数) + 负债总额 + 子女教育基金 - 现有人壽保额 - 可变现资产
危疾保障缺口 = (年收入 × 3~5) - 现有危疾保额
醫療缺口 = 私家医院费用标准 - 公司团险覆盖 - 现有个人醫療险
```

## 第四步：优先级排序

> 「根据刚才的分析，你目前最需要优先处理的是 ____。我建议我们可以分阶段来规划...」

**一般优先级建议**：
1. 🏥 醫療保障（最基本的保障，生病住院马上需要）
2. 🛡️ 人壽保障（有家庭负担的情况下优先）
3. 🏥 危疾（年轻时保费低，越早买越划算）
4. 💰 儲蓄保險 / 投資成分保險 + 退休收入（在保障到位后再考虑）

## 第五步：预算确认

> 「根据你的情况，我建议保费预算大约在每月 $____ 到 $____ 之间，大约占你收入的 X%。这个范围你觉得可以接受吗？」

**行业参考**：保费占家庭收入 10-15% 为合理范围

## 话术锦囊

### 客户说「我已经有公司团险了」
> 「公司团险是很好的基本保障，但有几点需要注意：第一，团险在你离开公司后就没有了；第二，团险通常有上限，大病费用可能不够；第三，团险不包含危疾赔偿金。我们可以看看你的团险覆盖范围，然后补充不足的部分。」

### 客户说「我还年轻，不急」
> 「其实越年轻买越有优势：保费更低、核保更容易通过、保障期更长。举个例子，同样的危疾保障，25岁买和35岁买，总保费可能差了30-40%。」
