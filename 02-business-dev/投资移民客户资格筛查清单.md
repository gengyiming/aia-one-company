# 投资移民客户资格筛查清单（15分钟）

专题入口：`[[_agent-system/topics/香港新资本投资者入境计划-专题总控]]`

## 1. 首轮资格 Gate（先判定能否进入深谈）

- [ ] 年龄 >= 18 岁
- [ ] 身份类别符合新计划适用范围（含是否为排除国籍）
- [ ] 申请前 6 个月持续绝对实益拥有 >= HKD 30M 净资产
- [ ] 可在规定时限内完成 >= HKD 30M 获许投资资产配置
- [ ] 无不良入境记录，且可证明本人及受养人有生计与住所能力

结论标签（只能选一项）：
- `可推进`
- `资料待补`
- `暂不匹配`

## 2. 15分钟访谈脚本（首访）

1. 身份与目标确认  
要点：申请动机、时间窗口、是否带受养人。

2. 资产与资金路径确认  
要点：近 6 个月净资产构成、可证明材料、资金可调度节奏。

3. 投资偏好确认  
要点：金融资产/房地产/投资组合偏好，流动性要求和风险偏好。

4. 时限与流程确认  
要点：是否能配合“原则上批准后窗口期”完成承诺投资与审查文件。

5. 合规声明  
要点：仅做计划信息与保险/财富规划支持；移民法律与税务意见由专业机构出具。

## 3. 必要资料清单（客户版）

- 身份文件与居留相关文件
- 近 6 个月净资产证明（银行、证券、不动产等支持文件）
- 资金来源与可调度证明
- 受养人关系证明（如适用）
- 既有投资与保单清单（便于做资产与保障协同规划）

## 4. 与 Pipeline 字段对齐（直接可录入）

| Pipeline 字段 | 填写规则（投资移民场景） |
|---|---|
| `status` | 新线索 / 已接触 / 需求分析中 / 方案呈现 / 促成中 |
| `category` | 投资移民 |
| `source` | 转介绍 / 内容获客 / 活动 / 其他 |
| `next_followup` | 首访后 3-7 天内设置下一步 |
| `annual_income_range` | 按模板填写区间 |
| `family_status` | 单身 / 已婚 / 已婚有子女 / 其他 |

推荐在客户档案备注补充：
- CIES 资格初筛结论（可推进/资料待补/暂不匹配）
- 净资产证明完整度（高/中/低）
- 目标递件时间（YYYY-MM）

## 5. 风险提示与边界（必须口头+书面）

- 官方文件会更新，必须以递交申请当日官方版本为准。
- 中文文件仅作参考，关键条款需回看英文规则文本。
- 不承诺审批结果、不承诺投资回报、不替代法律/税务意见。

以下情形必须转介：
- 复杂身份/居留历史 -> 移民律师
- 税务居民身份冲突或跨境税务问题 -> 税务顾问
- 大额资产证明链条复杂 -> 执业会计师

## 6. 下一步动作（团队执行）

- 业务部：在 `[[02-business-dev/客户Pipeline]]` 建立“投资移民”线索并推进 FNA。
- 客服部：提前准备受养人及后续服务材料清单框架。
- 数据部：纳入 `[[05-data-analytics/tracking/投资移民线索追踪]]` 漏斗统计。
