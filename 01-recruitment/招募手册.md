# 招募手册 — 增员SOP

## 招募流程总览

```
1. 目标人才画像 → 2. 线索获取 → 3. 初次邀约 → 4. Career Talk/面试
     → 5. 深度沟通 → 6. 入职决策 → 7. 牌照考试 → 8. 新人培训
```

## 1. 目标人才画像

### A级候选人（优先招募）
- 大学学位，25-40岁
- 有销售/客户服务/银行/金融经验
- 人脉资源丰富（如：银行客户经理、地产经纪、教师、医生）
- 自驱力强，对收入有较高追求
- 高才通/内地高端人才来港定居者

### B级候选人（值得培养）
- 大学学位，应届毕业或工作1-3年
- 虽无销售经验但学习能力强
- 愿意接受培训，认同保险业的价值
- AIA Premier Academy 适合的候选人

### 目标行业来源
| 行业 | 适合原因 | 邀约角度 |
|------|---------|---------|
| 银行 | 客户资源丰富，有金融知识 | 收入天花板突破，自主创业 |
| 地产 | 销售能力强，人脉广 | 更稳定的长期收入模式 |
| 教育 | 沟通能力强，人脉广 | 弹性时间，收入上不封顶 |
| 医疗 | 专业背景加分，高收入圈 | 帮人的使命感延伸 |
| IT/科技 | 高收入但发展焦虑 | 打造个人品牌和事业 |

## 2. 线索获取渠道

| 渠道 | 方法 | 产出预期 |
|------|------|---------|
| 转介绍 | 请团队成员和客户推荐 | 质量最高 |
| LinkedIn | 搜索目标画像，发送个性化邀请 | 覆盖面广 |
| 校园招募 | 大学career fair、讲座 | 量大，需筛选 |
| 行业活动 | BNI、商会、专业论坛 | 高质量人脉 |
| 社交媒体 | 个人品牌内容吸引 | 被动获取线索 |
| 高才通社群 | 内地人才来港社群 | 新兴优质渠道 |

## 3. AIA 入职流程

1. 通过面试和审核
2. 报考 IIQE Paper 1（保险原理及实务）
3. 通过考试后申请 IA 牌照
4. 完成 AIA 入职培训
5. 报考 Paper 3（长期保险），在限期内通过
6. 正式开始展业

## 4. 招募关键指标

| 指标 | 说明 | 建议目标 |
|------|------|---------|
| 每周接触新候选人数 | 初次邀约的人数 | ≥ 3人/周 |
| Career Talk 出席率 | 邀约到实际出席的转化率 | ≥ 50% |
| 面试到入职转化率 | 面试通过并入职的比例 | ≥ 30% |
| 新人13个月留存率 | 入职13个月后仍在职 | ≥ 60% |
| 新人首年活跃率 | 入职首年有出单 | ≥ 80% |
