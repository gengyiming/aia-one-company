# 新人 30-60-90 天入职计划

> 为新入职理财顾问量身定制的上手计划

## 新人姓名：_______ | 入职日期：_______

---

## 第一阶段：0-30天 — 打好基础

### 目标
- [ ] 通过 IIQE Paper 1 考试
- [ ] 熟悉AIA产品线（至少3个主力产品）
- [ ] 完成公司入职培训
- [ ] 列出100人名单

### 每周安排

**Week 1: 入职与考牌准备**
- [ ] 完成入职手续
- [ ] 领取学习资料
- [ ] 开始IIQE Paper 1备考
- [ ] 了解AIA公司文化和价值观

**Week 2: 密集备考**
- [ ] 完成Paper 1题库练习
- [ ] 参加团队早会感受氛围
- [ ] 开始学习基础产品知识

**Week 3: 考试+产品学习**
- [ ] 报名参加Paper 1考试
- [ ] 学习3个主力产品的基本卖点
- [ ] 完成100人名单（分A/B/C级）

**Week 4: 实战准备**
- [ ] 通过Paper 1考试（未通过则安排补考）
- [ ] 申请IA牌照
- [ ] 学习基本销售流程（FNA）
- [ ] 与经理进行角色扮演训练

---

## 第二阶段：30-60天 — 开始实战

### 目标
- [ ] 完成首月活动量目标（见X位客户）
- [ ] 开单（至少1单）
- [ ] 报考 IIQE Paper 3
- [ ] 建立日常工作习惯

### 每周安排

**Week 5-6: 开始展业**
- [ ] 从A级名单开始联系
- [ ] 经理陪同拜访2-3位客户
- [ ] 每天复盘销售过程
- [ ] 参加团队培训课程

**Week 7-8: 独立展业**
- [ ] 独立完成客户拜访
- [ ] 完成首单！
- [ ] 通过Paper 3考试
- [ ] 建立每周活动计划习惯

---

## 第三阶段：60-90天 — 稳定产出

### 目标
- [ ] 月均出单≥2单
- [ ] 掌握至少5个产品的完整讲解
- [ ] 获得至少1个转介绍
- [ ] 形成稳定的工作节奏

### 重点
- 提升Case Size
- 学习异议处理 → [[02-business-dev/scripts/异议处理话术]]
- 建立个人客户管理系统
- 开始经营个人品牌 → [[04-content-marketing/营销手册]]
