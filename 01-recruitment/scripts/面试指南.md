# 面试指南

## 面试流程

| 阶段 | 时间 | 内容 |
|------|------|------|
| 破冰 | 5分钟 | 自我介绍，营造轻松氛围 |
| 了解背景 | 10分钟 | 学历、工作经验、转行原因 |
| 评估适合度 | 15分钟 | 核心素质提问 |
| Career Presentation | 15分钟 | 介绍AIA和事业机会 |
| Q&A | 10分钟 | 回答候选人提问 |
| 下一步 | 5分钟 | 明确后续安排 |

## 核心评估维度

### 1. 动机 (Motivation) — 最重要
- 为什么想了解这个行业？
- 你对未来3-5年的职业期望是什么？
- 你能接受前期收入不稳定的挑战吗？

### 2. 人脉资源 (Network)
- 你的社交圈主要是什么类型的人？
- 你身边有多少朋友是你可以聊保障规划的？
- 你参与哪些社群或组织？

### 3. 学习能力 (Learnability)
- 你通常怎么学习新事物？
- 说说你最近学会的一项新技能。
- 你对金融/保险知识了解多少？

### 4. 抗压能力 (Resilience)
- 说说你遇到过的最大职业挫折，你是怎么应对的？
- 如果连续3个月没有成交，你会怎么做？
- 你怎么看待被拒绝？

### 5. 沟通能力 (Communication)
- 观察面试过程中的表达能力
- 是否善于倾听？
- 能否清晰表达自己的想法？

## Career Presentation 大纲

### 1. AIA简介（3分钟）
- 全球最大上市寿险集团
- 香港市场领导地位
- MDRT 全球第一大公司

### 2. 行业机遇（3分钟）
- 香港保险市场增长趋势
- GBA 大湾区机遇
- 内地客户（MCV）市场
- AI 时代对行业的影响

### 3. 事业平台（5分钟）
- 晋升制度：FP → DD → RD
- 收入模式：佣金 + 续期 + Override
- 培训体系：Premier Academy / Start-Up Elite
- 成功案例分享

### 4. 为什么是现在（2分钟）
- 你的背景优势
- 当前市场窗口
- 早期优势

### 5. 下一步（2分钟）
- 考牌流程和时间线
- 入职安排
- 支持体系
