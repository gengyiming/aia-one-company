# 客户服务手册 — SOP

## 服务理念

> 每一次服务都是加深关系的机会，每一个客户都是潜在的转介绍来源。

## 客户生命周期服务

| 时间节点 | 服务动作 | 目的 |
|---------|---------|------|
| 成交当天 | 感谢消息 + 确认后续流程 | 确立服务关系 |
| 成交后1周 | 确认保单资料收妥 | 专业可靠感 |
| 成交后1个月 | 关怀回访 | 持续关注 |
| 成交后3个月 | 首次简单检视 | 确认保障理解 |
| 每年保单周年 | 年度保单检视 | 深度服务 + 加保机会 |
| 客户生日 | 生日祝福 | 关系维护 |
| 重要节日 | 节日问候 | 存在感 |
| 客户生活变化 | 主动联系 | 加保/调整时机 |

## 年度保单检视流程

1. **提前2周**：发送预约消息
2. **准备**：检视客户所有保单，分析保障缺口
3. **检视会面**（约30-45分钟）：
   - 回顾家庭/工作变化
   - 检视现有保障是否足够
   - 分析新的保障需求
   - 提出建议（加保/调整）
4. **会后**：发送检视报告摘要
5. **跟进**：根据建议安排后续

详见 [[scripts/年度保单检视话术]]

## 续保管理

- 保费到期前1个月提醒
- 到期前2周确认缴费情况
- 逾期后立即跟进
- 详见 [[scripts/续保跟进话术]]

## 理赔服务

- 接到客户通知后24小时内响应
- 协助准备所有必要文件
- 全程跟进理赔进度
- 详见 [[scripts/理赔流程指引]]

## 加保时机识别

关键生活事件 = 加保机会：
- 结婚 → 人寿+医疗
- 生小孩 → 人寿+教育储蓄+危疾
- 买房 → 人寿（覆盖房贷）
- 升职加薪 → 全面升级保障
- 父母退休 → 医疗+年金

详见 [[scripts/加保时机与话术]]

## 转介绍策略

最佳请求转介绍的时机：
1. 理赔成功后（客户最感激的时候）
2. 年度检视后（刚感受到你的专业服务）
3. 客户主动夸赞你的服务时

话术：
> 「很高兴能帮到你。如果你身边有朋友也需要专业的保障规划，欢迎介绍给我。我会用同样的态度服务他们。」
