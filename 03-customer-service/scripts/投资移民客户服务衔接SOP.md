# 投资移民客户服务衔接 SOP

目标：在业务首访后，把投资移民客户的服务动作标准化，确保资料推进、沟通节奏与边界合规。

专题入口：`[[_agent-system/topics/香港新资本投资者入境计划-专题总控]]`

## 适用场景

- 客户已通过初筛或处于“资料待补”阶段
- 需要客服协同推进资料清单、跟进节奏与服务记录

## 服务流程

1. 接收业务移交
- 从业务获取：筛查结论、缺失资料、目标时间线
- 关联文件：[[02-business-dev/投资移民客户资格筛查清单]]

2. 建立服务记录
- 在客户档案写入“投资移民专题”标签
- 标注下次跟进时间（`next_followup`）

3. 资料清单协同
- 协助客户按清单准备并分批核对
- 缺失项用 `待补` 状态跟踪

4. 风险边界提示
- 仅做流程协同与资料推进
- 涉及法律/税务意见立即转介专业机构

5. 周度回传
- 向业务与数据回传：资料完整度、推进状态、阻塞原因

## 关键字段建议

- 资格结论：可推进 / 资料待补 / 暂不匹配
- 资料完整度：高 / 中 / 低
- 目标节点：下次会谈 / 预计递件启动日期
- 阻塞原因：身份核验 / 资产证明 / 时间安排 / 其他
