# 理赔流程指引

## 第一步：接到客户通知

> 「[称呼]，知道你的情况了。你先不要担心，我会全程协助你处理理赔。我现在帮你看看需要准备哪些文件，然后一步步来。」

## 理赔类型与所需文件

### 住院理赔
- [ ] 理赔申请表（AIA表格）
- [ ] 主诊医生报告
- [ ] 住院账单/收据正本
- [ ] 入院记录/出院摘要
- [ ] 身份证副本
- [ ] 银行账户资料（用于赔偿入账）

### 危疾理赔
- [ ] 理赔申请表
- [ ] 确诊报告/病理报告
- [ ] 主诊医生填写的医疗报告
- [ ] 所有相关检查报告
- [ ] 身份证副本
- [ ] 银行账户资料

### 意外理赔
- [ ] 理赔申请表
- [ ] 意外报告/警察报告（如适用）
- [ ] 医疗证明/诊断书
- [ ] 医疗费用收据正本
- [ ] 身份证副本

### 身故理赔
- [ ] 理赔申请表
- [ ] 死亡证明书
- [ ] 身份证副本（受保人+受益人）
- [ ] 受益人关系证明
- [ ] 银行账户资料（受益人）

## 理赔流程

```
1. 收集文件 → 2. 填写申请表 → 3. 提交AIA → 4. 公司审核
     → 5. 补充资料（如需要）→ 6. 理赔批核 → 7. 赔偿入账
```

**处理时间参考**：
- 简单住院理赔：约5-10个工作天
- 危疾理赔：约15-20个工作天
- 复杂案件：可能需要更长时间

## 理赔跟进话术

### 提交后
> 「文件我已经帮你提交了，公司正在审核中。通常[XX理赔]大约需要[X]个工作天。如果公司需要补充任何资料，我会第一时间通知你。」

### 理赔成功
> 「好消息！你的理赔已经批核了，赔偿金额$[XX]会在[X]个工作天内入账。你确认一下银行账户有没有收到。如果有任何问题随时找我。」

> 「希望你身体早日康复。如果之后需要任何帮助，随时联系我。」

## 重要提醒

- 保留所有医疗文件正本
- 尽早通知保险公司（不要等出院后太久）
- 如有公司团险，可以同时申请团险和个人险理赔
- 注意保单的等候期和除外条款

---

> 💡 **知识复利**：每次理赔经验（成功或被拒）都要记录，特别是公司的审核标准变化。
