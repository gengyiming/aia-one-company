# 客户总览

> Map of Content: 所有客户档案索引

## Dataview 自动汇总

```dataview
TABLE status AS "状态", policies AS "保单", next_followup AS "下次跟进", annual_premium AS "年保费"
FROM "03-customer-service/clients"
WHERE file.name != "_客户总览" AND file.name != "_客户档案模板"
SORT next_followup ASC
```

## 近期需跟进客户

```dataview
LIST
FROM "03-customer-service/clients"
WHERE next_followup <= date(today) + dur(14 days)
WHERE file.name != "_客户总览" AND file.name != "_客户档案模板"
SORT next_followup ASC
```

| 级别 | 标准 | 服务频率 |

| A级 | 年保费 $30,000-100,000 | 半年主动联系 |
