# 待办事项

> 每周由客服部Agent更新，汇总所有客户档案中的待办

## Dataview 自动汇总

### 近7天需跟进

```dataview
TABLE next_followup AS "日期", status AS "状态"
FROM "03-customer-service/clients"
WHERE next_followup <= date(today) + dur(7 days)
WHERE file.name != "_客户总览" AND file.name != "_客户档案模板"
SORT next_followup ASC
```

### 本月生日客户

```dataview
LIST
FROM "03-customer-service/clients"
WHERE dateformat(birthday, "MM") = dateformat(date(today), "MM")
WHERE file.name != "_客户总览" AND file.name != "_客户档案模板"
```
