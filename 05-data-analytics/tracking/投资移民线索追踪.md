# 投资移民线索追踪

专题入口：`[[_agent-system/topics/香港新资本投资者入境计划-专题总控]]`

## 指标定义（漏斗）

| 阶段 | 英文 | 定义 | 口径说明 |
|---|---|---|---|
| 新线索 | Lead | 首次进入Pipeline且可联系 | 去重后按自然人统计 |
| 资格预审通过 | Qualified | 通过首轮 Gate（年龄/身份/净资产/投资能力） | 参考 [[02-business-dev/投资移民客户资格筛查清单]] |
| 深度会谈完成 | Discovery Done | 已完成完整需求访谈与资料清单确认 | 含下一步时间承诺 |
| 资料齐备 | Docs Ready | 关键文件达到可递交状态 | 不含法律意见书本身 |
| 递件启动 | Submission Started | 已进入正式申请执行流程 | 以“启动日”计入 |
| 原则上批准 | AIP | 获原则上批准 | 来自客户确认+文件 |
| 正式批准 | Formal Approval | 获正式批准 | 来自客户确认+文件 |

核心转化率：
- `资格通过率 = 资格预审通过 / 新线索`
- `递件启动率 = 递件启动 / 资格预审通过`
- `AIP率 = 原则上批准 / 递件启动`
- `正式批准率 = 正式批准 / 原则上批准`
