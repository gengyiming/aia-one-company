# 知识健康度仪表盘

> 用途：追踪全公司知识库的覆盖率、新鲜度和增长趋势。配合 [[_agent-system/intake/知识生命周期SOP]] 使用。

## 知识新鲜度总览

### 过期文件（>180天未更新）

```dataview
TABLE file.folder AS "所在部门", updated AS "最近更新"
FROM "01-recruitment" OR "02-business-dev" OR "03-customer-service" OR "04-content-marketing" OR "05-data-analytics" OR "_resources"
WHERE updated AND (date(today) - updated > dur(180 days))
WHERE status != "archived" AND status != "deprecated"
SORT updated ASC
```

### 待复核文件（90-180天未更新）

```dataview
TABLE file.folder AS "所在部门", updated AS "最近更新"
FROM "01-recruitment" OR "02-business-dev" OR "03-customer-service" OR "04-content-marketing" OR "05-data-analytics" OR "_resources"
WHERE updated AND (date(today) - updated > dur(90 days)) AND (date(today) - updated <= dur(180 days))
WHERE status != "archived" AND status != "deprecated"
SORT updated ASC
```

## 各部门知识文件统计

```dataview
TABLE length(rows) AS "知识文件数"
FROM "01-recruitment" OR "02-business-dev" OR "03-customer-service" OR "04-content-marketing" OR "05-data-analytics"
WHERE status != "archived" AND status != "deprecated"
GROUP BY regexreplace(file.folder, "/.*", "")
SORT length(rows) DESC
```

## 最近 7 天知识变更

```dataview
TABLE file.folder AS "位置", updated AS "更新日期"
FROM "01-recruitment" OR "02-business-dev" OR "03-customer-service" OR "04-content-marketing" OR "05-data-analytics" OR "_resources"
WHERE updated >= date(today) - dur(7 days)
SORT updated DESC
```
