# 数据管理手册

## 核心指标定义

### 业绩指标

| 指标 | 英文 | 定义 | 计算方式 |
|------|------|------|---------|
| FYP | First Year Premium | 首年保费 | 新单年化保费总和 |
| FYC | First Year Commission | 首年佣金 | FYP × 佣金率 |
| ANP | Annualized New Premium | 年化新保费 | 年化计算的新业务量 |
| Case Count | - | 成交单数 | 新签保单数量 |
| Case Size | - | 平均单量 | FYP ÷ Case Count |

### 活动量指标

| 指标 | 定义 | 建议目标 |
|------|------|---------|
| 邀约数 | 主动联系的客户/候选人数 | ≥15/周 |
| 见面数 | 实际见面的次数 | ≥5/周 |
| FNA数 | 完成需求分析的次数 | ≥3/周 |
| 提案数 | 提交方案建议的次数 | ≥2/周 |
| 成交数 | 签单的次数 | ≥1/周 |

### 转化率

| 指标 | 计算 | 健康水平 |
|------|------|---------|
| 邀约→见面 | 见面数 ÷ 邀约数 | ≥40% |
| 见面→FNA | FNA数 ÷ 见面数 | ≥60% |
| FNA→提案 | 提案数 ÷ FNA数 | ≥80% |
| 提案→成交 | 成交数 ÷ 提案数 | ≥40% |
| 整体转化率 | 成交数 ÷ 邀约数 | ≥5-10% |

## MDRT 资格标准

> 以下为参考标准，具体以当年MDRT官方公布为准

| 级别 | FYC 标准 (约) | FYP 标准 (约) | 说明 |
|------|--------------|--------------|------|
| MDRT | ~US$82,000 | 约 HK$500,000+ | 百万圆桌 |
| COT | ~US$246,000 | 约 HK$1,500,000+ | 3倍MDRT |
| TOT | ~US$492,000 | 约 HK$3,000,000+ | 6倍MDRT |

## 数据更新频率

| 数据 | 更新频率 | 负责 |
|------|---------|------|
| 活动量 | 每日/每周 | CEO录入 |
| 业绩数据 | 每周 | CEO录入 |
| MDRT进度 | 每月 | 数据部Agent计算 |
| 团队表现 | 每月 | CEO录入 |
| 收入 | 每月 | CEO录入 |
| 周报 | 每周日 | 数据部Agent生成 |
| 月报 | 每月初 | 数据部Agent生成 |
