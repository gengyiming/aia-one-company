# 分派经验

## 已验证规则

### 场景：PDF 官方文件解析
- 最佳分派：`data_analytics` 先做结构化解析
- 需 cc：`business_dev`
- 注意：若是产品资料，必须二次回写产品卡并校验 Dataview 字段

### 场景：产品问答与对比
- 最佳分派：`business_dev`
- 需 cc：`content_marketing`（若需对外内容化）
- 注意：答案需同轮回写到知识库

## 常见失败模式
- 任务 done 但缺结构化输出链接
- 产品文件 done 但未回写产品卡
