## 本周到期任务（跨部门）

```dataview
TABLE due as "截止", from_agent as "发起", to_agent as "接收", priority as "优先级", status as "状态", deliverable as "交付"
FROM "_agent-system/tasks"
WHERE status != "done" AND due >= date(today) AND due <= date(today) + dur(7 days)
SORT due asc, priority desc
```

## 未完成任务总览（按部门）

```dataview
TABLE length(rows) as "未完成任务数"
FROM "_agent-system/tasks"
WHERE status != "done"
GROUP BY to_agent
SORT length(rows) desc
```

## 高优先级待办（CEO先看）

```dataview
TABLE file.link as "任务", due as "截止", from_agent as "发起", to_agent as "接收", status as "状态"
FROM "_agent-system/tasks"
WHERE status != "done" AND priority = "high"
SORT due asc
```

## CIES 专题任务看板

```dataview
TABLE task_id as "任务ID", from_agent as "发起", to_agent as "接收", priority as "优先级", due as "截止", status as "状态", deliverable as "交付"
FROM "_agent-system/tasks"
WHERE contains(tags, "投资移民") OR contains(tags, "CIES")
SORT due asc
```
