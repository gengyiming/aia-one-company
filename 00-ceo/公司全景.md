# 公司全景

## 愿景

成为香港AIA最具系统化运营能力的理财团队，通过AI驱动的知识管理实现业务倍增。

## 使命

- 为每一位客户提供专业、贴心的财务保障方案
- 建立一支高素质、高留存的理财顾问团队
- 用系统化方法持续提升个人和团队生产力

## 组织架构

```
CEO（我）
│
├── 🎯 招募部 — 团队建设与人才引进
│   目标：持续吸引优质人才，壮大团队
│
├── 📈 业务拓展部 — 客户开发与销售
│   目标：拓展新客户，提升Case Size和Case Count
│
├── 🤝 客户服务部 — 客户关系管理
│   目标：提升续保率，深化客户关系，挖掘加保机会
│
├── 📱 内容营销部 — 品牌与获客
│   目标：打造个人专业品牌，通过内容吸引潜在客户和候选人
│
└── 📊 数据分析部 — 业绩与目标管理
    目标：用数据驱动决策，追踪目标达成进度
```

## 核心价值观

1. **客户至上**：一切以客户利益为出发点
2. **专业为本**：持续学习，提供最专业的建议
3. **知识复利**：每一次工作都积累为可复用的知识资产
4. **数据驱动**：用数据说话，用数据决策
