# 办公环境 — Wi-Fi 信号诊断指南

> **适用场景**：家庭/办公室 Wi-Fi 信号弱、时断时续、视频会议卡顿。作为一人公司，稳定网络是线上展业（Zoom 面谈、远程递交、直播）的基础设施。
> **来源与核对日期**：通用网络工程常识整理，2026-08-09。

## 第一步：先分清「宽带问题」还是「Wi-Fi 问题」

这是最关键的分岔点，决定后面往哪个方向查：

1. **贴着路由器测速**（用 speedtest.net 或 fast.com）
2. **在信号差的位置再测一次**
3. 有条件的话，**用网线直连路由器测一次**

| 结果 | 结论 |
|------|------|
| 贴近测速也慢/不稳 | 宽带或路由器本身的问题 → 找运营商或换路由器 |
| 贴近正常、远处变差 | 典型 Wi-Fi 覆盖/干扰问题 → 按下文排查 |
| 有线快、无线全程慢 | 路由器无线部分（老化/设置）问题 |

## 第二步：量化信号强度（RSSI）

不要凭"格数"判断，看 dBm 数值：

- **Windows**：命令行运行 `netsh wlan show interfaces`，看 Signal 百分比（约 50% 以下即偏弱）
- **macOS**：按住 Option 点击菜单栏 Wi-Fi 图标，直接显示 RSSI 和信道
- **手机**：装 WiFi 分析仪类 App（Android 可看邻居信道分布）

判读标准：

| RSSI | 体验 |
|------|------|
| -50 dBm 以上 | 优秀 |
| -50 ~ -65 dBm | 良好，视频会议无压力 |
| -65 ~ -75 dBm | 一般，可能偶尔卡顿 |
| -75 dBm 以下 | 差，断流、掉线高发区 |

## 常见原因与对策（按出现频率排序）

### 1. 路由器摆放位置不佳
- 藏在弱电箱/电视柜里、贴地、靠墙角 → 信号被大幅衰减
- **对策**：放在户型居中位置、离地 1 米以上、周围开阔；天线竖直

### 2. 2.4GHz 频段拥挤（高层住宅重灾区）
- 邻居 Wi-Fi、蓝牙、微波炉都挤在 2.4GHz；香港/内地高密度住宅尤其严重
- **对策**：用 WiFi 分析仪查看邻居信道，手动固定到 1/6/11 中最空的一个；近距离设备优先连 5GHz

### 3. 5GHz 穿墙能力差
- 5GHz 快但穿一堵承重墙就明显衰减
- **对策**：把 2.4G 和 5G 分成两个 SSID，近处连 5G、远房间连 2.4G；或部署 Mesh

### 4. 路由器老化 / 固件 / 过热
- 运行 5 年以上、机身烫手、越用越慢重启就好 → 硬件在退化
- **对策**：升级固件；定期重启；超过 5 年直接换 Wi-Fi 6/6E 路由器，性价比最高的单项升级

### 5. 墙体与障碍物
- 承重墙、金属柜、镜子、鱼缸/热水器（水对 2.4GHz 吸收强）都会挡信号
- **对策**：调整路由器与常用办公位之间的直线路径，避开上述障碍

### 6. 设备过多 / 带宽被占
- 智能家居 + 手机 + 电脑几十个设备挂在一台入门路由器上
- **对策**：登录路由器管理页看在线设备数和流量；开 QoS 优先保障办公电脑；踢掉可疑蹭网设备并改密码

### 7. Mesh / 中继粘滞
- 用了 Mesh 或中继器，但设备"粘"在远处弱信号节点不切换
- **对策**：检查节点摆放（每个节点之间信号应 ≥ -65 dBm）；开关 Wi-Fi 强制重连

## 系统化排查顺序（10 分钟版）

1. 重启路由器和光猫（断电 30 秒）——排除临时故障
2. 贴近路由器测速 → 定位是宽带还是覆盖问题
3. 查 RSSI → 确认弱信号区域
4. 查信道占用 → 换到空闲信道
5. 调整路由器位置 → 复测
6. 仍不行 → 按预算升级（见下）

## 升级方案分级

| 预算 | 方案 | 适合 |
|------|------|------|
| 免费 | 挪位置、换信道、分 SSID、升固件 | 先全部做完再谈花钱 |
| 低 | 网线 + 二手路由器做 AP；或电力猫 | 有预埋网线/插座顺路的户型 |
| 中 | 双节点 Mesh（Wi-Fi 6） | 100㎡+ 或多隔间户型，一劳永逸 |
| 高 | 全屋有线回程 AP | 装修期或对稳定性要求极高（如常态直播） |

## 边界与风险

- 本指南针对常规家用/小型办公环境；企业级网络（VLAN、认证）不在范围内
- 运营商侧故障（区域性网络劣化、光衰过大）个人无法解决，需报障
- 改信道/固件升级前记下原设置，异常可回退
