# 知识地图

> **用途**：按主题（而非部门）组织的全局知识索引。一页浏览全公司知识资产，发现缺口，避免重复。

## 产品知识

### 产品卡（已建立）

```dataview
TABLE official_name AS "产品名称", category AS "类别", status AS "状态", updated AS "最近更新"
FROM "02-business-dev/knowledge/product-cards"
SORT category ASC, updated DESC
```

### 产品线知识文件

```dataview
TABLE updated AS "最近更新", length(file.outlinks) AS "外链数"
```

## 知识统计

### 各部门知识文件数

```dataview
TABLE length(rows) AS "文件数"
FROM "01-recruitment" OR "02-business-dev" OR "03-customer-service" OR "04-content-marketing" OR "05-data-analytics"
WHERE !contains(file.path, "cases/")
GROUP BY regexreplace(file.folder, "/.*", "") AS "部门"
SORT length(rows) DESC
```

### 最近 30 天更新的知识文件

```dataview
TABLE file.folder AS "所在部门", updated AS "更新日期"
FROM "01-recruitment" OR "02-business-dev" OR "03-customer-service" OR "04-content-marketing" OR "05-data-analytics" OR "_resources"
WHERE updated >= date(today) - dur(30 days)
SORT updated DESC
```
