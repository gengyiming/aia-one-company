# 合规提醒

## 核心原则

1. **不保证回报**：任何涉及分红、投资回报的表述必须注明「非保证」
2. **适合性评估**：推荐产品前必须进行财务需要分析（FNA）
3. **充分披露**：确保客户了解产品条款、除外责任、冷静期权利
4. **真实宣传**：所有营销内容不得有误导性或夸大的表述
5. **客户隐私**：严格遵守《个人资料（私隐）条例》，客户资料不得泄露

## 营销内容注意事项

- 不得在社交媒体发布未经合规审核的产品广告
- 避免使用「保证」、「无风险」、「稳赚」等措辞
- 引用数据需注明来源和日期
- 客户见证/案例需获得书面同意并适当匿名化

## 招募注意事项

- 不得以不实的收入承诺进行招募
- 介绍晋升制度时需说明这取决于个人表现
- 牌照考试和合规培训是入职必要条件
