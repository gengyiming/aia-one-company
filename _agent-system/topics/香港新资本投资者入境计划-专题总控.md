# 香港新资本投资者入境计划（CIES）专题总控

## 专题目标

- 把“香港新资本投资者入境计划”作为独立经营专题长期运行。
- 所有相关输入统一由 CEO 接收，再按规则分派到部门执行。
- 形成“官方口径 -> 销售筛查 -> 内容转化 -> 线索追踪 -> 客服衔接”的闭环。

## 范围边界

纳入范围：
- 官方规则/指南更新
- 客户资格筛查与案例推进
- 对外内容解读与获客
- 线索漏斗追踪与复盘
- 客户服务衔接（续跟进/资料准备/服务边界）

不纳入范围：
- 法律意见、税务意见、审批承诺（需转介专业机构）

## 近期规则更新（2026-03-01 生效）

- 更新点：就“合资格私人控权公司”安排，若该公司在提交投资规定审查申请前成立少于 6 个月，审查投资规定时不设最少成立期要求。
- 业务影响：客户若以“合资格私人控权公司”承接获许投资资产，不再因公司成立未满 6 个月而必须等待；但其他资格条件与证明文件要求维持。
- 执行口径：所有对外说明必须带上“生效日：2026-03-01”，并同步核对最新《计划规则》英文版条文。

  - 新资本投资者入境计划规则页面：https://www.newcies.gov.hk/zh-hk/resources/scheme-rules-and-documents/
