## 多任务拆分规则

当 CEO Agent 判断一个输入需要多个部门协作时：

1. **主任务 + 子任务**模式：创建一个主任务（`from_agent: ceo`），再为每个协作部门创建子任务（`depends_on: 主任务ID`）
2. **命名规范**：主任务 `TASK-YYYYMMDD-XXX`，子任务 `TASK-YYYYMMDD-XXX-a/b/c`
3. **并行 vs 串行**：
   - 各部门可独立执行 → 并行创建，不设 `depends_on`
   - 需要上游输出 → 串行创建，设置 `depends_on`
4. **汇总验收**：所有子任务完成后，CEO 在主任务中汇总验收
