# 记忆维护 SOP

目标：保持 CEO 记忆系统准确、精简、可执行。

## 每周维护（周复盘时执行）

1. 检查 `00-ceo/ceo-memory/` 四个文件是否本周有更新
2. 清理重复/过时条目
3. 新增“当前关注重点”与“本周决策规则”
4. `version +1` 并更新 `updated`

## 每月整理

1. 合并相近规则，删除冗余描述
2. 把待确认条目单列，准备下轮向用户确认
3. 输出一页《本月用户偏好摘要》到 `决策日志.md`

## 季度回顾

1. 对照 `季度OKR.md` 验证偏好与决策规则有效性
2. 归档失效规则到附录区
3. 保留下季度仍有效的核心规则
