## 逻辑识别

- 类型：`policy`
- 原文结构：定义与适用范围 -> 资格准则 -> 投资规定 -> 申请与逗留 -> 延期与长期路径 -> 终止/撤销。
- 解析方式：按规则执行链路组织，不按通用“摘要/字段/风险”模板拆分。

## 执行链路（可直接用于一线）

1. 准入判断：身份类别、年龄、入境记录。
2. 资产判断：申请前 6 个月持续绝对实益拥有净资产不少于 HKD 30M。
3. 投资判断：可在规定时限完成不少于 HKD 30M 获许投资配置。
4. 时限判断：原则上批准后窗口期内完成投资及审查动作。
5. 持续合规：正式批准后按规则维持投资，进入续签与 7 年路径管理。
