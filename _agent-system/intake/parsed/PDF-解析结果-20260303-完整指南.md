# 解析结果：新資本投資者入境計劃的完整指南

## 文档定位（对客沟通主文件）

这份指南是“客户沟通入口文档”，逻辑是：计划价值说明 -> 资格门槛 -> 申请流程 -> 投资资产范围 -> 联络与提交渠道。它不是规则细则，因此要和规则主文件配套使用。

## 沟通逻辑链（按首访流程）

1. 为什么是香港：先讲制度与环境优势。  
2. 谁可以申请：再讲身份类别、年龄和排除范围。  
3. 要满足什么门槛：净资产要求 + 最低投资要求。  
4. 怎么走流程：净资产审查 -> 原则上批准 -> 投资审查 -> 正式批准 -> 后续续签。  
5. 投资放哪里：获许资产与上限口径。  
6. 何时找专业支持：边界外问题转介律师/税务顾问。

## 客户最常问的5个问题（对应证据）

| 客户问题 | 指南口径 | 证据页 |
|---|---|---|
| 我是否符合身份范围 | 外国国民、已取得外国永久身份中国籍人士、澳门居民、台湾华籍居民（含排除说明） | p2 |
| 门槛到底是多少 | 净资产 HKD 30M + 投资 HKD 30M | p2 |
| 申请流程怎么走 | 净资产审查到正式批准的分段流程 | p3 |
| CIES 投资组合是多少 | HKD 3M（锁定期） | p4 |
| 房地产和存款证上限 | 房地产总上限 15M、住宅 10M、存款证 3M | p4 |

## 与规则主文件的分工

- 指南：用于说明和引导，适合首访、内容营销、FAQ。  
- 规则：用于定性和定量判断，适合资格审查、投资合规和流程卡点处理。

实操顺序建议：先用指南讲清框架，再用规则锁定细节。
