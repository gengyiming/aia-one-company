# 解析结果：新資本投資者入境計劃的規則

## 文档定位（规则主文件）

这份文件是 CIES 的规则底座，不是宣传页。其逻辑顺序是：定义与反规避 -> 资格 -> 投资要求 -> 申请与逗留 -> 续签与长期路径 -> 终止与撤销。

## 目录逻辑映射（用于实操检索）

| 逻辑块 | 你要回答的问题 | 首选证据位置 |
|---|---|---|
| 资格准则 | 谁可以申请、谁被排除 | 规则目录 + 资格章节 |
| 净资产规定 | 3000万如何定义与证明 | 净资产章节 |
| 获许投资资产 | 什么资产可计入 | 获许投资资产章节 |
| 审批与时限 | AIP 后多久要完成投资 | 申请程序/逗留章节 |
| 延长逗留 | 续签条件和节奏 | 延长逗留章节 |
| 7年路径 | 永居或无条件逗留条件 | 长期留港路径章节 |

## 执行口径主链（按客户咨询顺序）

1. 准入：先判断身份类别与年龄，再判断是否有不良入境记录。
2. 财务：核验申请前 6 个月持续绝对实益拥有不少于 HKD 30M 净资产。
3. 投资：确认可在规则窗口内完成不少于 HKD 30M 的获许投资配置。
4. 时限：原则上批准后，访客逗留期内完成承诺投资并进入后续审查。
5. 持续合规：正式批准后要按规定维持投资，才能顺利续签与走向 7 年路径。

## 关键修订点（版本敏感）

- 2025-09-17：房地产计入门槛与上限口径有更新。
- 2026-03-01：合资格私人公司相关条件有更新。

这两项会直接影响“可计入金额”和“结构设计方案”，销售与筛查必须标注版本日期。

## 给各部门的落地接口

- `business_dev`：用此文件定义资格 Gate、资料清单、时限提醒。
- `content_marketing`：所有对外内容先用指南讲解，再回链本规则做底层证据。
- `data_analytics`：漏斗节点定义（预审/投资完成/AIP/正式批准）应与本规则一致。
- `customer_service`：跟进节奏以规则时限管理，避免错过窗口。
