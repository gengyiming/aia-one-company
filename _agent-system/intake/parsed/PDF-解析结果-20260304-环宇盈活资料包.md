# 解析结果：环宇盈活产品资料包

## 资料包逻辑拆分（不是一份文档）

| 文件 | 角色 | 你该用它回答什么 |
|---|---|---|
| 产品资料册 | 内部发布与版本背景 | 产品定位、上市节奏、内部说明 |
| GF 产品小册子 | 产品机制主文档 | 场景、功能、限制、条款提示 |
| 一页精华 | 前线速查页 | 关键利益数字与触发时点 |
| 计划PPT | 销售展示材料 | 沟通表达、场景演示、地域销售提示 |

## 产品价值逻辑（客户视角）

核心主张不是“单一高收益”，而是“长期资产规划中的弹性管理”：

1. 长期价值：以长期持有为前提的非保证回报潜力。  
2. 现金流弹性：可按规则在特定年度后申请提取。  
3. 货币管理：可在规定窗口申请货币转换。  
4. 家庭与传承：围绕教育、退休、传承等场景使用。

## 关键触发时间轴（执行最常用）

| 机制 | 最早时点 | 证据 |
|---|---|---|
| 灵活提取选项 | 第5个保单年度终结后或保费缴付期完结后（以较后者为准） | 一页精华 p1 脚注3；GF小册子 p12 |
| 货币转换选项 | 第2个保单年度终结后，每个保单年度完结后30日内可申请一次 | 一页精华 p1 脚注2；GF小册子 p12 |
| 价值保障选项 | 第6个保单年度终结后 | 一页精华 p1 脚注4 |
| 红利及分红锁定 | 第15个保单年度终结后 | 一页精华 p1 脚注5 |

## 利益口径（必须与风险提示绑定）

- 示例口径：第30个保单年度终结时预期总内部回报率可达 6.5%（非保证）。
- 同页存在悲观情景示例：3.48%（5年缴费个案）。

对外表达时必须把“非保证”“个案假设”“示例条件”放在同一段，不可拆开。

## 限制与边界（避免误售）

- 公司投保限制：灵活提取选项不适用于公司投保保单。
- 地域提示：资料含“只于香港及澳门派发”“只可在香港作寿险销售用途”等表述。
- 结论：这些提示反映的是销售/派发场景，不等同最终核保准入结果。

## 执行落地接口

- `business_dev`：按“价值逻辑 + 时间轴 + 限制条款”更新话术。
- `customer_service`：把提取/转换条件写入后续服务提醒。
- `content_marketing`：优先产出“规则速查卡（含限制与风险）”。
- `data_analytics`：客户意图标签建议加入“教育/退休/传承/公司投保”。
