# 任务分派预检 SOP

目标：在创建任务前完成最小质量检查，避免无效分派与返工。

## 预检清单（全部通过才可创建任务单）

### 1. 必要性检查
- [ ] 该事项不能由 CEO 直接在同轮答复完成
- [ ] 该事项确实需要部门执行动作

### 2. 输入完整性
- [ ] 已有结构化输入文件（`_agent-system/intake/parsed/`）
- [ ] 关键字段齐全（目标、范围、截止时间、证据来源）
- [ ] 缺失项已标注并可被执行方理解

### 3. 路由判断
- [ ] `to_agent` 明确且唯一主责
- [ ] `cc_agents` 已覆盖必要协作方
- [ ] 若跨部门任务，`cc_agents` 必须包含 `ceo`

### 4. 验收标准
- [ ] `deliverable` 为可打开的 `[[双向链接]]`
- [ ] 交付标准可被验证（至少2条）
- [ ] `due` 与 `priority` 合理

### 5. 用户确认
- [ ] 已向用户展示分派摘要（目标/部门/截止）
- [ ] 用户无异议或已完成修正

## 输出动作

通过预检后：
1. 使用 `[[_agent-system/templates/任务单模板]]` 创建任务
2. 填写 frontmatter 完整字段
3. 更新 `_agent-system/inbox` 可见状态

预检不通过：
1. 暂不分派
2. 记录缺失项
3. 补齐后再进入分派
