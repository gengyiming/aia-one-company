# Git 提交信息模板

格式：

```text
<type>(<scope>): <简要描述>
```

## type

- `feat`：新增能力/内容
- `update`：更新既有内容
- `task`：任务推进/交付
- `sop`：SOP/流程规则改动
- `fix`：修复错误
- `chore`：杂项维护

## scope

- `ceo`
- `recruitment`
- `business-dev`
- `customer-service`
- `content-marketing`
- `data-analytics`
- `agent-system`
- `knowledge`

## 示例

- `sop(agent-system): 新增任务分派预检SOP`
- `update(ceo): 增加CEO记忆系统与周复盘规则`
- `task(TASK-20260304-PDF-003): 完成环宇盈活资料解析回写`
